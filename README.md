# trailOS

Local-first activity tracker for hiking, running and cycling.

## Goals

- Record GPS activities
- Keep ownership of activity data
- Export and import GPX
- Sync with Nextcloud
- Import Garmin FIT activities
- Build statistics and activity history
- Avoid mandatory paid subscriptions
- Record hiking, running and cycling activities
- Track GPS position, distance, duration and speed
- Store activities locally
- Export and import GPX files
- Sync activities with Nextcloud
- Import Garmin FIT activities
- Provide personal statistics and activity history
- Support offline use whenever possible

## Principles

- Local-first
- User owns the data
- Open formats where possible
- External services are optional integrations
- No mandatory subscription
